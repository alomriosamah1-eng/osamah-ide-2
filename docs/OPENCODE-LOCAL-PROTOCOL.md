# بروتوكول OpenCode المحلي

## النطاق

هذا البروتوكول يعرّف الاتصال المحلي بين Osamah IDE وخادم OpenCode الذي يشغّله المستخدم. وصف «محلي» هنا يعني **عنوان خادم OpenCode على الحلقة المحلية**، وليس نموذج LLM محلياً. لا يفعّل التشغيل عن بُعد، ولا يتجاوز مفاتيح المزودين، ولا يمنح أدوات التنفيذ أي صلاحيات ضمنية.

## أساس المصدر

تمت مطابقة المسارات مع SDK الرسمي الموجود في نسخة المصادر المحلية لـ OpenCode. نقطة التشغيل تضبط المضيف الافتراضي على `127.0.0.1`، وتدعم تحديد `port` و`cors` صراحةً. لا ينبغي استخدام `0.0.0.0` أو mDNS في وضع Osamah المحلي إلا بقرار أمني مستقل.

| الغرض | عملية OpenCode الأصلية | استخدام Osamah |
|---|---|---|
| فحص الجاهزية | `GET /api/health` | اختبار الوصول فقط وعرض حالة الاتصال |
| اكتشاف المزودين | `GET /api/provider` | استبعاد المزوّدات المعطّلة وعرض مسمياتها |
| اكتشاف النماذج | `GET /api/model` | ملء قائمة النماذج الحية عند اتصال موثوق |
| إنشاء جلسة | `POST /api/session` | إنشاء جلسة مرتبطة بمساحة عمل محددة |
| إرسال رسالة | `POST /api/session/{sessionID}/prompt` | تنفيذ طلب المحادثة عبر النموذج المختار |
| أحداث الجلسة | `GET /api/session/{sessionID}/event` | استلام أحداث البث عند إضافة المرحلة لاحقاً |

## سياسة الاتصال

1. يقبل العميل عنواناً محلياً فقط: `localhost` أو `127.0.0.1` أو `[::1]`.
2. القيمة الافتراضية المقترحة هي `http://127.0.0.1:4096`، لكنها **ليست** دليلاً على وجود خادم؛ يجب أن يثبت فحص الصحة ذلك.
3. يمرر المستخدم أصل واجهة Osamah في إعداد `--cors` عند تشغيل OpenCode المحلي.
4. لا تخزن مفاتيح المزودين أو رموز OpenCode في `localStorage` أو في واجهة المتصفح.
5. عند أي فشل شبكة أو CORS أو استجابة غير صالحة، تتحول الحالة إلى `غير متصل` ولا تُنشأ رسائل رد محاكاة.

## حدود الصلاحيات

واجهة Osamah تستطيع الاستعلام عن الصحة والمزودين فقط قبل موافقة المستخدم. أما إنشاء الجلسات وإرسال الرسائل واستدعاء الأدوات فيتطلب مساراً صريحاً، مساحة عمل معتمدة، وسياسة صلاحيات منفصلة. مسارات shell وPTY وMCP ليست مفعلة في هذه المرحلة.

## معايير قبول الخطوة التالية

- نجاح `GET /api/health` من خادم OpenCode على الحلقة المحلية ومفعّل CORS.
- تحويل الاستجابة الحقيقية من `/api/provider` و`/api/model` إلى `OpenCodeModelPreference` من دون نماذج ثابتة.
- عدم تبديل الواجهة إلى حالة متصل قبل فحص صحة ناجح.
- استمرار التطبيق بالعمل في حالة عدم وجود OpenCode محلي.
