## عائق الرفع

في محاولة الدفع إلى `github/main` فشل Git على طبقة المصادقة برسالة `Invalid username or token`. فحص موصل GitHub الحالي يؤكد أنه **مفعّل**، لكن رمز GitHub CLI الحالي غير صالح. كما أن صفحة المستودع العامة الظاهرة في المتصفح غير مسجّل الدخول فيها، وآخر التزام بعيد ظاهر هو `30cca25`.

> لا توجد إعادة محاولة عمياء أو تغيير لبيانات الاعتماد. يبقى الالتزام المحلي محفوظاً وجاهزاً للدفع فور تجدد رمز GitHub أو جلسة موثوقة.
