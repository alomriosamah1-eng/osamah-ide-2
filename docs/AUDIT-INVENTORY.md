# جرد الصفحات والعقود والكيانات

## المسارات والشاشات

| المسار أو الحالة | المكوّن | العمليات الخادمية المرتبطة | الكيانات | ما سيُثبت في التدقيق |
|---|---|---|---|---|
| `/` بلا جلسة | `Home` ثم `AuthGate` | `auth.local.register`, `login`, `recoveryQuestion`, `verifyRecoveryAnswer`, `resetPassword`, `logout` | `users`, `localAccounts` | إنشاء حساب بلا اسم/بريد، الدخول، تحقق إجابة الاسترداد قبل إعادة التعيين، Cookie الجلسة، وعرض الأخطاء |
| `/` بجلسة | `Home` ثم `OsamahWorkspace` | `preferences.get`, `workspace.*`, `engines.status`, `opencode.*` | تفضيلات المستخدم، المشاريع والمهام والنشاط | الانتقال الصحيح، إبطال cache بعد العمليات، الحالات الفارغة والأخطاء |
| البرمجة | قسم Programming داخل `OsamahWorkspace` | `workspace.project.*`, `workspace.file.*`, `workspace.task.*`, `workspace.activity.list`, `theia.*` | `projects`, `projectFiles`, `tasks`, `activityLog` | الملكية، إنشاء/فتح/حفظ/إعادة تسمية/حذف، وعرض حالة Theia بصدق |
| العروض | `PresentationStudio` | `presentations.*`, `presenton.status` | `presentations`, `presentationSlides`, `activityLog` | إنشاء العرض والشرائح، التعديل، الحذف، إعادة الترتيب، وحالة Presenton |
| العقل الثاني | قسم Second Mind داخل `OsamahWorkspace` | `secondBrain.*` | `knowledgeItems`, `knowledgeLinks`, `tasks` | CRUD، البحث، الروابط، استخلاص وتحويل المهام، وعزل الملكية |
| لوحة الوكيل | `OsamahWorkspace` | `engines.status`, `opencode.status/models/session/*` | لا تحفظ رسائل وكيل مصطنعة | عرض حالة المحركات والسياق المصرّح به، وتعطيل الإرسال عند غياب نموذج |
| الإعدادات | `ServerSettingsView` | `preferences.get/update`, `auth.local.updateProfile` | `userPreferences`, `users`, `localAccounts` | حفظ اللغة والمظهر ونمط الوكيل، وعرض التكاملات غير المهيأة بوضوح |
| `/404` | `NotFound` | لا شيء | لا شيء | رابط عودة واضح وتباين مناسب |

## جرد `workspace` التفصيلي

| المسار | القراءة | التعديل | القيود في العقد |
|---|---|---|---|
| `workspace.project` | `list`, `get` | `create`, `update`, `remove` | اسم مشروع 1–160، حالة `active/archived`، ملكية المستخدم |
| `workspace.file` | `list`, `get` | `create`, `save`, `rename`, `remove` | مشروع مملوك، مسار طبيعي وفريد، نوع ملف/مجلد، محتوى أقصاه 100,000 حرف |
| `workspace.task` | `list`, `get` | `create`, `update`, `remove` | عنوان 1–240، حالة مهمة مضبوطة، مشروع اختياري لكن مملوك |
| `workspace.activity` | `list` | لا تعديل مباشر | حد 1–100 وسجل ناتج عن عمليات فعلية |

## جرد المصادر والأقسام الخدمية

| النطاق | القراءة | التعديل | الحراسة أو القيد الملحوظ |
|---|---|---|---|
| `secondBrain.items` | قائمة/عنصر/بحث | إنشاء/تعديل/حذف | كل عنصر مملوك للمستخدم الحالي |
| `secondBrain.links` | روابط العنصر | إنشاء/تعديل ملصق/حذف | مالك الطرفين، منع الرابط الذاتي والتكرار |
| `secondBrain.tasks` | مرشحو استخلاص المهام | تحويل مهمة من ملاحظة | يستدعي محول المصدر الأصلي، لا نموذج بديل |
| `presentations` | قائمة/عرض/شرائح | عرض وشرائح وإعادة ترتيب | العرض والشرائح مملوكان، ترتيب الشريحة فريد |
| `preferences` | تفضيلات المستخدم | تحديث جزئي | قيم تعداد اللغة/المظهر/نمط الوكيل |
| `engines` | حالة المحركات والسياق | لا تعديل تنفيذي | سياق القسم محصور بالبيانات المملوكة للمستخدم |
| `opencode` | الحالة، المصدر، النماذج، الرسائل، الأذونات | جلسة/إرسال/انتظار/قرار | التنفيذ لا يمر إلا عبر إجراء مخصص وبمزود ونموذج صالحين |
| `theia` | المصدر والحالة | لا تشغيل من المتصفح | لا runtime يدعى جاهزاً بلا artifact |
| `presenton` | المصدر والحالة | لا توليد من الجسر | فحص FastAPI لا يعني جاهزية توليد أو تصدير |

## حالات الاختبار الإلزامية المشتقة من الجرد

| المجال | الحالات الأساسية | الحالات الطرفية |
|---|---|---|
| الحساب | إنشاء، دخول، خروج، سؤال الاسترداد، تحقق الإجابة، إعادة التعيين | كلمة مرور خاطئة، إجابة خاطئة، حساب جهاز مكرر، مدخلات ناقصة |
| المشروع والملفات | CRUD وحفظ وإعادة تسمية | مشروع/ملف غير مملوك، مسار مكرر، مدخل بلا تغيير، محتوى طويل |
| المهام | CRUD والربط بالمشروع وتغير الحالة | مشروع غير مملوك، انتقال فارغ، حذف مشروع مرتبط |
| المعرفة | CRUD والبحث والروابط واستخلاص مهام | رابط لنفسه، تكرار، طرف غير مملوك، إدخال فارغ |
| العروض | CRUD وشرائح وترتيب | عرض غير مملوك، شريحة غير مملوكة، ترتيب ناقص أو مكرر |
| الواجهة | العربية والإنجليزية، RTL/LTR، المظهران | تحميل، خطأ tRPC، فراغ، زر معطّل، تركيز لوحة المفاتيح |
| المحركات | حالة الجسر والحماية قبل التشغيل | غياب نموذج OpenCode، غياب artifact Theia، غياب مزود Presenton |
