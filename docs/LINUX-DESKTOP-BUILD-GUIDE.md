# دليل البناء التلقائي لتطبيق سطح المكتب لنظام Ubuntu Linux

## نظرة عامة
تم تجهيز المستودع بالكامل ليدعم البناء الآلي المستمر (CI/CD) وإنتاج حزم تثبيت سطح المكتب لنظام **Ubuntu Linux (x64)** عبر GitHub Actions.

---

## 1. مسارات العمل المؤتمتة (GitHub Actions Workflows)

يحتوي المستودع على مساري عمل:
1. **`.github/workflows/ci.yml`**:
   - يتحقق من سلامة الأكواد والأنواع (`pnpm check`).
   - يشغل كافة الاختبارات الآلية (`pnpm test`).
   - يتحقق من حدود التكامل وتغطية التوثيق (`pnpm run audit:jsdoc`).
2. **`.github/workflows/build-linux-desktop.yml`**:
   - يُبنى تلقائياً عند الدفع لفرع `main`، أو إطلاق إصدار جديد (`v*`)، أو يدوياً عبر `workflow_dispatch`.
   - يبني أصول الواجهة والخلفية (`pnpm run build`).
   - يُنشئ حزمة التثبيت الرسمية لنظام أوبونتو **`.deb`** وحزمة التشغيل المستقلة **`.tar.gz`**.
   - يرفع الحزم الجاهزة كـ Artifacts ويُنشئ Releases تلقائية عند استخدام الوسوم (Tags).

---

## 2. مخرجات البناء (Build Artifacts)

| نوع الحزمة | الامتداد | طريقة الاستخدام |
|---|---|---|
| **حزمة دبيان / أوبونتو** | `osamah-ide_1.0.0_amd64.deb` | تثبيت نظامي يضيف التطبيق لقائمة البرامج والأيقونات والأوامر (`/usr/bin/osamah-ide`). |
| **الحزمة المحمولة (Portable)** | `osamah-ide-linux-x64.tar.gz` | حزمة مستقلة لا تتطلب صلاحيات جذر، مع سكريبت تثبيت اختصار سطح المكتب. |

---

## 3. طريقة تثبيت وتشغيل التطبيق على Ubuntu

### الطريقة الأولى: تثبيت حزمة `.deb`
```bash
# تثبيت الحزمة
sudo dpkg -i osamah-ide_1.0.0_amd64.deb

# في حال وجود تبعيات ناقصة
sudo apt-get install -f

# تشغيل التطبيق من سطر الأوامر أو من قائمة التطبيقات
osamah-ide
```

### الطريقة الثانية: تشغيل الحزمة المحمولة `.tar.gz`
```bash
tar -xzf osamah-ide-linux-x64.tar.gz
cd osamah-ide

# تشغيل التطبيق مباشرة
./desktop/launcher.sh

# أو تثبيت اختصار في قائمة التطبيقات المحلية
./install-desktop-shortcut.sh
```

---

## 4. مكونات تكامل سطح المكتب

- **ملف الاختصار (`desktop/osamah-ide.desktop`):** يتكامل مع بيئات GNOME/KDE ويوفر فئات `Development;IDE;`.
- **أيقونة التطبيق (`desktop/osamah-ide.svg`):** تصميم متجهي عالي الدقة بهوية مرصد الذكاء والمدار الأزرق `#5E8CFF`.
- **المُشغّل الذكي (`desktop/launcher.sh`):**
  - يقوم بتهيئة بيئة التشغيل الآمنة وتوليد المفاتيح السرية المحلية.
  - يشغل جسور المحركات الخلفية (FastAPI/Presenton وOpenCode).
  - يفتح واجهة التطبيق في نافذة سطح مكتب مستقلة (Standalone Window) عبر المتصفح الافتراضي.
