# عقد اتصال OpenCode

**الحالة:** اكتشاف حيّ من المتصفح متاح؛ تنفيذ الرسائل والجلسات ما زال غير مفعّل.

## قرار الاتصال الحالي

تتصل واجهة Osamah IDE مباشرةً بخادم **OpenCode** الذي يشغّله المستخدم على جهازه عبر الحلقة المحلية فقط. هذا اتصال بخادم OpenCode، **وليس نموذجاً محلياً**، ولا يستخدم Cloud Computer، ولا يحتفظ بمفاتيح مزودي النماذج في React أو `localStorage`.

يحفظ المتصفح عنوان الخادم المحلي فقط بعد تحقق ناجح. ولا يقبل العميل عناوين بعيدة أو مسارات أو بيانات اعتماد ضمن العنوان، إذ يقتصر على `127.0.0.1` أو `localhost` أو `::1` أو `opencode.local`.

## مصادر الحقيقة في OpenCode

اعتمدت طبقة الاكتشاف على عميل OpenCode المولّد في النسخة المستنسخة من المصدر الرسمي. المسارات الحالية هي `GET /api/health` و`GET /api/provider` و`GET /api/model`، وليس على مسارات مفترضة أو قائمة ثابتة.

| نتيجة OpenCode | تحويلها في Osamah IDE | قاعدة العرض |
|---|---|---|
| `{ healthy: true }` من `/api/health` | يبدأ الاكتشاف | لا تُعد الواجهة جاهزة قبل تحقق الصحة |
| `data[]` من `/api/provider` | أسماء المزودين وحالتهم | يستبعد المزود المعطّل |
| `data[]` من `/api/model` | `OpenCodeModelPreference` | يعرض فقط نموذجاً `enabled: true` لمزوّد غير معطّل |

## حالات الواجهة

| الحالة | المعنى | السلوك |
|---|---|---|
| `unconfigured` | لا عنوان محفوظ أو لا نموذج OpenCode مفعّل | تبقى القائمة معطّلة |
| `checking` | يجري فحص الصحة ثم قراءة المزوّدات والنماذج | لا تعرض الواجهة نتيجة مؤقتة |
| `ready` | اكتُشف نموذج مفعّل واحد على الأقل | تُمكّن الاختيار فقط؛ لا ترسل رسالة بعد |
| `offline` | تعذر الوصول إلى الخادم أو منعه المتصفح | لا تنشئ رداً بديلاً |
| `degraded` | عنوان غير صالح أو استجابة HTTP/JSON غير مطابقة | لا تنشئ رداً بديلاً |

## حدود المرحلة الحالية

لا تستدعي الواجهة في هذه المرحلة أي مسار جلسة أو رسالة أو أحداث. لذلك، حتى بعد نجاح الاكتشاف واختيار نموذج، تحفظ الدردشة الرسالة محلياً وتشرح بوضوح أن التنفيذ ينتظر إضافة الجلسات وتدفق الأحداث والموافقات.

يتطلب نجاح الاتصال أن يسمح خادم OpenCode لأصل الواجهة الحالية عبر إعداد CORS الخاص به. يدعم OpenCode تعيين نطاقات CORS إضافية في خيارات الشبكة، بينما يظل ربط الخادم نفسه افتراضياً على `127.0.0.1` ويمكن أن يختار منفذاً عند التشغيل؛ لذلك يُدخل المستخدم الأصل الفعلي الذي أعلنه OpenCode.

## المرحلة التنفيذية التالية

تُنفذ الجلسات والرسائل فقط بعد اختبار الاتصال مع خادم OpenCode حقيقي. وعندئذٍ يجب أن تضيف المرحلة التالية، بترتيب واضح، إنشاء أو استعادة جلسة، إرسال الرسالة بالنموذج المكتشف، تدفق أحداث الجلسة، وحاجز موافقة صريح قبل أي تنفيذ أدوات حساس.

## مراجع المصدر المحلي

1. `OSAMAH-STUDIO-SOURCES/opencode/packages/client/src/generated/client.ts` — تعريف المسارات الحالية.
2. `OSAMAH-STUDIO-SOURCES/opencode/packages/client/src/generated/types.ts` — مخططات الصحة والمزوّدات والنماذج وحالات تفعيلها.
3. `OSAMAH-STUDIO-SOURCES/opencode/packages/opencode/src/cli/network.ts` — إعدادات المضيف وCORS والشبكة.
