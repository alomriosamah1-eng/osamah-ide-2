# قرار اتصال OpenCode عبر متصفح بيئة العمل

## النتيجة

يُستخدم متصفح بيئة العمل لمعاينة Osamah IDE واختبار عنوان OpenCode المتاح له فقط. لا يُستخدم متصفح المستخدم الشخصي، وقد أُلغي الوصول المقترح إليه. كما لا يُستخدم Cloud Computer ولا تُشغّل نماذج LLM محلية.

## التحقق المنفذ

| الفحص | النتيجة | الأثر |
|---|---|---|
| `http://127.0.0.1:4096/api/health` من متصفح بيئة العمل | رُفض الاتصال | لا يوجد خادم OpenCode قابل للوصول على المنفذ الافتراضي |
| منافذ الحلقة المحلية في بيئة العمل | خدمات بيئة فقط، ولا توجد خدمة OpenCode | لا يجوز تخمين منفذ بديل أو اعتبار أي خدمة قائمة محرك OpenCode |
| توفر أمر `opencode` | غير مثبت | لا يمكن تشغيل خادم OpenCode من بيئة العمل الحالية من دون تثبيت وتشغيل جديدين |

## قرار التنفيذ

متصفح بيئة العمل **لا يشغّل OpenCode بذاته**؛ هو عميل HTTP فقط. لذلك تبقى الواجهة في وضع الاكتشاف الصادق ولا تُفعّل إنشاء الجلسات أو إرسال الرسائل حتى يتوفر خادم OpenCode حقيقي يمكن للمتصفح الوصول إليه. لا تُضاف مفاتيح مزودين أو نماذج افتراضية إلى الواجهة.

إذا اختار المستخدم مستقبلاً تشغيل OpenCode خارج هذه البيئة، يجب تقديم أصل حلقة محلية أو عنوان مسموح صراحةً ثم تفعيل CORS لأصل واجهة Osamah IDE. أما إذا كان المطلوب تشغيله من بيئة العمل نفسها، فيستلزم ذلك موافقة صريحة على تثبيت الأداة وتشغيل خدمة، وهو مسار مختلف عن استخدام المتصفح فقط.
