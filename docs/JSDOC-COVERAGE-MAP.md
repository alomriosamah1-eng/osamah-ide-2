# خريطة تغطية JSDoc لخلفية Osamah IDE

**الحالة:** مكتمل القياس في 26 أغسطس 2026
**الأداة:** `pnpm audit:jsdoc`
**تعريف التغطية:** يكون التصدير موثقاً عندما يسبقه مباشرة تعليق `/** ... */`، وتُحتسب ترويسة الملف فقط عندما تبدأ بـ`@fileoverview` في أول الملف. يميز التقرير كود الإنتاج من الاختبارات ولا يحسب الملفات المولدة من الإطار ضمن النسبة.

## النطاق والحدود

تشمل الخريطة `server/**` باستثناء `server/_core/**`. هذا الاستثناء ليس ادعاءً أن ملفات الإطار موثقة؛ بل لأنها بنية قالب غير مملوكة للمنتج، وقد يؤدي تعديلها إلى كسر تحديثات الإطار. لا تشمل الخريطة `third_party/**` لأن لقطات OpenCode وTheia وPresenton موردية وغير قابلة للتحرير بموجب حدود المشروع.

| الشريحة | الملفات | ترويسات `@fileoverview` | التصديرات | التصديرات الموثقة | التغطية الأساسية |
|---|---:|---:|---:|---:|---:|
| كود إنتاج خلفي | 23 | 23 | 128 | 128 | 100% |
| اختبارات خلفية | 15 | 0 | 0 | 0 | غير منطبق: لا صادرات عامة |
| الإجمالي المقاس | 38 | 23 | 128 | 128 | 100% للتصديرات العامة |

> هذه النسبة **تقيس موضع التعليق فقط**، وليست حكماً على جودة مضمونه. يُراجع المحتوى يدوياً خلال كل نطاق قبل اعتماده.

## معيار التوثيق المعتمد

| الرمز | الحد الأدنى المطلوب | إضافات عند الحاجة |
|---|---|---|
| ملف Backend تجاري | `@fileoverview` بالإنجليزية يشرح المسؤولية والحدود والاعتماديات | `@see` لراوتر/خدمة مرتبطة. |
| نوع أو Interface أو DTO | وصف الغرض ومصدر الملكية/الثقة | قيود المجال أو خيارات الاتحاد غير البديهية. |
| دالة تصديرية | فعل واضح، أثر على البيانات، وحدود الملكية إن وجدت | `@param` للمعنى الدلالي، `@returns` للضمان، `@throws` للأخطاء الفعلية فقط. |
| Router أو procedure builder | المجال والإجراءات المحمية ونمط العزل | `@see` لملف وصول البيانات واختبارات الملكية. |
| محول تكامل خارجي | المصدر الخارجي وحدود الجاهزية وعدم وجود fallback | متطلبات سرية أو علم بيئي من دون كشف قيم. |
| اختبار أو script | ترويسة موجزة أو اسم اختبار واضح | لا يلزم تكرار JSDoc لكل callback في `describe/it`. |

ينبغي أن تضيف التعليقات معرفة لا يستنتجها TypeScript من التوقيع. يدعم TypeDoc تعليقات `/** ... */` والوسوم TSDoc/JSDoc المتاخمة للتصريحات [1]، وتحدد وثائق JSDoc الوسوم القياسية مثل `@file`, `@param`, `@returns`, و`@throws` [2].

## خطة التنفيذ

1. **تثبيت القياس:** يبقى `JSDOC-COVERAGE.json` ناتجاً مولداً ولا يعدل يدوياً؛ يجدد بـ`pnpm audit:jsdoc`.
2. **نطاقات P0/P1/P2:** اكتملت الترويسات وتوثيق التصديرات العامة لكود الإنتاج المملوك: **23/23 ترويسة و128/128 تصديراً**.
3. **تكاملات غير مهيأة:** وثقت الحقيقة التشغيلية: لا مزوّد OpenCode، لا Theia browser artifact، ولا Presenton generation/export. لا تحول التعليقات حدوداً مقيدة إلى وعود تشغيلية.
4. **فجوة البوابة الحالية:** الفاحص يقيس ويولّد JSON لكنه لا يفشل بعد عند تراجع التغطية. قبل تفعيل ذلك في CI يجب الاتفاق على الحد الصارم والملفات المستثناة؛ لا يُدّعى وجود منع انحدار قبل إضافته واختباره.
