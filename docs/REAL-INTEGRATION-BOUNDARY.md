# حدود الدمج الفعلي للمصادر

يعتمد Osamah IDE على أربعة مصادر حقيقية فقط في مسار الدمج الحالي: **OpenCode** و**Eclipse Theia** و**Presenton** و**Second Brain**. يُستبعد **OmniRoute** صراحةً؛ لا يجوز إدخال مصدره أو تشغيله أو استخدامه كاعتمادية أو وصل واجهته أو خدمته داخل Osamah.

| المصدر | الالتزام المثبّت | وظيفته داخل Osamah | عقد التشغيل | حقيقة المرحلة الحالية |
|---|---:|---|---|---|
| OpenCode | `ac1c048e…` | جلسات الوكيل واكتشاف النماذج والموافقات وسياق الأقسام | Bun 1.3.14، خادم حلقة محلية عبر الغلاف الخادمي | المصدر والجلسة وفحص الصحة متحققان؛ لا يوجد مزوّد نموذج مهيأ |
| Eclipse Theia | `a35c2a27…` | إطار المحرر البرمجي ومساحة العمل | Node.js 22+ ومثال متصفح مبني | المصدر وبطاقة الحالة متحققان؛ البناء تجاوز حد الذاكرة |
| Presenton | `92033c1…` | محرر عروض Osamah وحالة المصدر تمهيداً لتوليد وتصدير Presenton | Next.js + FastAPI؛ إعدادات مزوّد من جهة الخادم | جسر الحالة وCRUD العروض والشرائح في Osamah متحققان؛ لم يبدأ خادم Presenton ولا يتاح توليد أو تصدير عبره |
| Second Brain | `2bd13c2…` | ملاحظات ومصادر وبحث ومهام ومعرفة | Python 3.11+ وSQLite محلي وخدمات اختيارية | موائم Python يستدعي `extract_candidates_from_text` من المصدر لاستخراج مهام الملاحظات؛ لا تشغّل بقية خدمات المصدر أو فهرسته |

كل لقطة مورد تحفظ غير معدّلة. تكتب موائمات Osamah في `server/` و`client/` فقط. لا يمر عنوان حلقة محلية أو مفتاح مزوّد أو صلاحية تشغيل إلى المتصفح؛ تتعامل الواجهة حصراً مع إجراءات tRPC خادمية محمية. يعرض عقد `engines.status` حالة المصادر الأربع من جسورها الحقيقية، بينما يبني `engines.context` أعداد مساحة عمل المستخدم وحالات الجاهزية من الخادم فقط.

> لا تعني واجهة موجودة أن الوظيفة تعمل. ستربط كل عملية إنشاء أو تعديل أو حذف أو حفظ أو إعادة تسمية أو تنفيذ بسجل خادمي قابل للاختبار، أو ستظهر كحالة غير متاحة موضحة السبب إلى أن يتحقق تشغيل المصدر الأصلي.

## حواجز التنفيذ المقصودة

لا يستخدم المسار أي نموذج محلي أو افتراض لمزوّد أو fallback. لا يُشغّل OpenCode جلسة وكيل في النشر العام دون تفويض خادمي صريح وإعداد مزوّد حقيقي. ولا يبدأ Theia قبل وجود نواتج مثال المتصفح؛ كما لا يبدأ Presenton أو Second Brain قبل تثبيت اعتمادياتهما وتهيئة التخزين والأسرار الملائمة.

استبعدت لقطة Presenton ذاكرة `FastEmbed` المولّدة التي كانت تتضمن نموذجاً محلياً مخزناً؛ ولم تثبّت الإضافات الاختيارية المحلية في Second Brain (`sentence-transformers` أو `faster-whisper`). تبقى وحدات المصدر التي تعرف هذه الخيارات كما هي، لكن لا تُشغّل ولا تمثل جزءاً من مسار Osamah.

بيانات المنتجات التي ينشئها المستخدم — المشاريع والملفات والمهام والملاحظات والعروض وسجل النشاط — ستكون مملوكة لطبقة Osamah وقابلة للحماية لكل مستخدم. أما طبقات المورد فتقدم محركات متخصصة عبر موائمات محدودة وواضحة، وليست بديلاً عن تفويض التطبيق أو تخزينه.

## العمليات المتحققة في طبقة Osamah

| المجال | العملية المثبتة | الحماية والتحقق | الحد الصريح |
|---|---|---|---|
| الحساب والتفضيلات | إنشاء حساب محلي بكلمة مرور وسؤال/جواب استرداد فقط، وتسجيل الدخول والاسترداد وتحديث الملف والتفضيلات | كلمة المرور وإجابة الاسترداد بتجزئة `scrypt`؛ جلسة JWT في cookie `HttpOnly`؛ تفضيلات لكل مستخدم | لا تحفظ كلمة مرور أو رمز جلسة في `localStorage`، ولا يطلب الإنشاء الاسم أو البريد |
| البرمجة | CRUD للمشاريع والملفات والمهام وسجل النشاط | إجراءات tRPC محمية وملكية على مستوى المستخدم؛ تحقق HTTP طرفي ينظف بياناته | Theia لم يبنَ، لذا لا يوجد محرر Theia أو زر تشغيل فعلي |
| العقل الثاني | CRUD للملاحظات والمصادر والروابط، بحث بالنص وتسمية الرابط، استخراج مهام وترحيلها | ملكية طرفي الرابط، منع الرابط الذاتي والتكرار، ورسائل فشل وإعادة محاولة في الواجهة | لا توجد فهرسة دلالية أو خدمة مستمرة أو نموذج محلي |
| العروض | CRUD للعروض والشرائح وإعادة ترتيبها وتسجيل النشاط | ملكية العرض والشرائح وتحقق HTTP طرفي ينظف بياناته | لا يولّد Presenton شرائح أو ملفات حتى يبدأ خادمه ويجهّز مزوّده خادمياً |
| OpenCode | حالة الغلاف الخادمي، فحص الصحة وإنشاء جلسة في بيئة الاختبار، وسياق قسم مبني خادمياً عند إرسال الرسالة | الوصول عبر tRPC وجلسة حساب محلية خادمية؛ التنفيذ محجوب افتراضياً بعلم بيئي | لا مزوّد نموذج مهيأ؛ لذلك لا استجابة محادثة أو موافقة E2E مدعاة، ولا تدّعي الواجهة أن Theia أو Presenton نفّذا عملاً |

تستخدم لوحات العرض والإشعارات حالة المشروع وسجل النشاط وحالات الموارد الخادمية. ولا تظهر واجهة Chat أو OpenCode رسالة وكيل أو موافقة إلا بعد ورودها من الإجراءات الخادمية؛ وعند غياب المزوّد تعرض حالة غير مهيأة بدلاً من قائمة نماذج أو نشاط مصطنع.

## عقد المحركات وسياق الوكيل

تتصل لوحة الوكيل بإجراء `engines.context` المحمي، وتعرض لكل قسم حالة OpenCode وTheia وPresenton وSecond Brain كما تبلغ عنها جسور المصادر. عند إرسال رسالة إلى جلسة OpenCode — وهو مسار لا يُتاح إلا بحساب محلي وجلسة تنفيذ مفعلة ومزوّد مكتشف — يبني الخادم غلاف سياق يتضمن القسم المحدد، وأعداد المشاريع والمهام وعناصر المعرفة والعروض المملوكة للحساب، وحالات جاهزية المحركات. لا يمرر العميل هذا السياق ولا يمكنه تزوير أعداد المستخدم أو إعلان جاهزية محرك غير مهيأ.

> وجود سياق خادمي لا يساوي قدرة تنفيذ. OpenCode لا يستطيع حالياً استدعاء Theia أو Presenton أو Second Brain كأدوات لأن نموذج OpenCode ومزوّده غير مهيأين، ولأن Theia لم يُبنَ وPresenton لم يبدأ. السياق يضمن أن أول اتصال فعلي لاحق يبدأ بحالة دقيقة ومملوكة للحساب فقط.
